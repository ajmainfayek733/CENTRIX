# A true production-grade browser Monitor on Windows

**A professional browser monitor typically uses different strategies depending on the browser.**

| Browser |                                                     Method |
| :------ | ---------------------------------------------------------: |
| Chrome  |                   UI Automation + Chrome DevTools Protocol |
| Edge    |                          UI Automation + DevTools Protocol |
| Brave   |                                        UI Automation + CDP |
| Opera   |                                              UI Automation |
| Firefox | UI Automation (no stable CDP equivalent for this use case) |

## Production-grade edge cases

A robust implementation should handle at least the following:

[x] Browser process exits during inspection.
[x] Browser launches but has no active window.
[x] Multiple browser windows are open.
[x] Incognito/Private windows (where URL access may be restricted).
[x] Browser running with elevated privileges while the agent is not.
[x] Browser running under another Windows user session.
[x] URL changes while being read.
[x] Tabs still loading.
[x] about:blank.
[x] chrome://_, edge://_, brave://_, opera://_.
[x] file://.
[x] data:.
[x] mailto:.
[x] javascript:.
[x] ftp://.
[x] localhost.
[x] IPv4 and IPv6 hosts.
[x] Internationalized domain names (IDN).
[x] UI Automation timeouts and COM exceptions.
[x] Accessibility APIs being unavailable.
[x] Permission and integrity-level mismatches.
[x] Browser crashes or restarts during inspection.
