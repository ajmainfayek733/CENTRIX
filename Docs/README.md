## Conventions used in these documents

- **Source references are relative paths from the repository root**, so
  `Backend/src/modules/ingest/ingestService.ts` is clickable in an editor and greppable in a
  terminal.
- **Every document ends with a `Related` section.** Following those links is how you get from
  a symptom to a mechanism to the code.
- **"Why" lives in the source.** These documents explain structure, contracts and failure
  behaviour; the reasoning behind a specific line is in the comment above that line. Where a
  document restates a reason, it is because the reason spans files.
- **Nothing here is generated.** If code changes and a document does not, the document is
  wrong - fix it in the same commit.
