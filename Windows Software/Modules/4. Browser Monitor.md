# A true production-grade browser Monitor on Windows

**A professional browser monitor typically uses different strategies depending on the browser.**

| Browser |                                                     Method |
| :------ | ---------------------------------------------------------: |
| Chrome  |                   UI Automation + Chrome DevTools Protocol |
| Edge    |                          UI Automation + DevTools Protocol |
| Brave   |                                        UI Automation + CDP |
| Opera   |                                              UI Automation |
| Firefox | UI Automation (no stable CDP equivalent for this use case) |

## Production-grade edge cases

A robust implementation should handle at least the following:

[✔] Browser process exits during inspection.
[✔] Browser launches but has no active window.
[✔] Multiple browser windows are open.
[✔] Incognito/Private windows (where URL access may be restricted).
[✔] Browser running with elevated privileges while the agent is not.
[✔] Browser running under another Windows user session.
[✔] URL changes while being read.
[✔] Tabs still loading.
[✔] about:blank.
[✔] chrome://_, edge://_, brave://_, opera://_.
[✔] file://.
[✔] data:.
[✔] mailto:.
[✔] javascript:.
[✔] ftp://.
[✔] localhost.
[✔] IPv4 and IPv6 hosts.
[✔] Internationalized domain names (IDN).
[✔] UI Automation timeouts and COM exceptions.
[✔] Accessibility APIs being unavailable.
[✔] Permission and integrity-level mismatches.
[✔] Browser crashes or restarts during inspection.
