## Required Windows APIs

| --------------------- | ---------------------------------------------------------------- |
| Foreground window     | `GetForegroundWindow`                                            |
| Window title          | `GetWindowTextW`                                                 |
| Process ID            | `GetWindowThreadProcessId`                                       |

## Enterprise Edge Cases

Your monitor should explicitly handle:

- Fast User Switching
- Multiple concurrent Windows sessions
- RDP connect/disconnect
- Console connect/disconnect
- Lock/unlock
- Sleep/hibernate/resume
- System shutdown/restart
- Explorer restart
- Process termination
- Window title changes
- Browser tab changes
- UAC elevation prompts (foreground switches to the secure desktop)
- Monitor sleep
- Service restart after crash
- Clock adjustments (prefer monotonic timers such as - Stopwatch for duration calculations)
- High CPU usage from excessive polling
- Database write failures with retry and local buffering
