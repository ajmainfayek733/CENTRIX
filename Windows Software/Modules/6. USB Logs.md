# Enterprise USB monitoring service

**Purpose:** Detect that Windows physically attached or removed a USB storage device.

---

## Physical Device Detection

```
RegisterDeviceNotification()

WM_DEVICECHANGE

DBT_DEVICEARRIVAL

DBT_DEVICEREMOVECOMPLETE

DBT_DEVNODES_CHANGED
```

**Advantages:**

- Immediate
- Very reliable
- No polling

**Detects:**

- Physical insertion
- Physical removal
- Surprise removal
- USB hub disconnect

**Limitations:**

Does NOT tell

- Drive letter
- Volume label
- Mounted partition

---

## PnP Device Enumeration

After arrival event

```
Win32_DiskDrive
↓
Win32_DiskPartition
↓
Win32_LogicalDisk
```

**Collect:**

- Vendor ID: `VID_xxxx`
- Product ID: `PID_xxxx`
- Serial Number
- PNPDeviceID
- Friendly Name
- Bus Type
- Interface Type
- Capacity
- Manufacturer

**Never identify devices using:** Drive letters. Drive letters change.

---

## Volume Detection

**Detect**

- Drive mounted
- Drive unmounted
- Volume label changes
- Filesystem changes

```
Win32_VolumeChangeEvent

OR

FindFirstVolume()
FindNextVolume()
```

## Active Reconciliation Engine

Runs every: 3-10 seconds

**Purpose:**

- Recover from
- Missed WMI event
- Missed Device Notification
- Explorer crash
- Windows restart
- Unexpected failures

**Algorithm:**

```
Current Devices
↓
Compare
↓
Previous Snapshot
↓
Generate Missing Events
```

Guarantee eventual consistency.

---

## USB Session State Machine

Never store only insertion/removal.

**Maintain a session.**

```
Unknown
↓
Inserted
↓
Mounted
↓
In Use
↓
Safe Remove Requested
↓
Unmounted
↓
Removed
↓
Archived
```

Every state transition is logged.

---

## Session Model

```
USB Device

↓

USB Session

↓

Events
```

**One device may have:** 100 sessions

**Each session contains:**

```
Inserted Time
Removed Time
Duration
Computer
User
Policies
Drive Letters
File Activity
```

## Device Identity

Never use Drive Letter

**Use**

Priority:

1. Serial Number
2. PNPDeviceID
3. Volume GUID
4. Vendor+Product
5. Drive Letter (temporary only)

## Removal Detection

**Handle:**

- Explorer Eject
- Physical Pull
- Power Loss
- USB Hub Disconnect
- Dock Removal
- Sleep Resume
- Hibernate Resume
- Blue Screen Recovery
- Explorer Restart
- Fast Startup
- Unexpected Shutdown
- Each removal has different Windows events.
- The reconciliation engine should normalize them.

## Phones

- iPhone
- MTP
- PTP

## Encrypted Drives

## Edge Cases

- Same drive inserted twice quickly
- Two identical USB devices
- Duplicate serial numbers (common on cheap flash drives)
- Drive letter reassigned while connected
- Multiple partitions on one device
- Volume label changes during session
- Filesystem corruption
- Delayed mount after insertion
- Device detected but no media present
- USB connected through a hub that is unplugged
- Simultaneous insertion/removal of multiple devices
- Windows clock adjusted during a session
- Agent starts with USB already connected
- Agent stops and restarts while USB remains connected
- SQLite temporarily locked or unavailable
- Network unavailable during event upload
- Missed WMI or device-notification events recovered by reconciliation
